# PesaEarn 💰

A simulated "watch & earn" platform UI built with pure HTML, CSS, and JavaScript.

## Pages
- **`index.html`** — Login / Sign in page with validation + redirect
- **`dashboard.html`** — Earnings dashboard with fake video watching + $5 withdrawal fee

## Features
- 🎨 Modern dark UI, mobile-first (390px phone frame)
- 🔐 Login form validation (email + password)
- 👁️ Password visibility toggle
- 🔄 Redirects to dashboard on successful login
- 💵 Fake video watching increases balance
- ⚠️ $5 withdrawal fee modal (simulated)
- 🚪 Logout returns to login page

## ⚠️ Disclaimer
This is a **UI/UX demo only**. No real money, no real payments, no real authentication.
Do **not** use this to deceive or defraud anyone.

## Run Locally
Just open `index.html` in your browser — no build step needed.
